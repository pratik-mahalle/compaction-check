# compaction-check 0.2.0a1 — developer alpha

Long-running agents can lose a requirement when conversation history is summarized. This release stores reviewed requirements outside the summary, restores their current wording, and asks Jev to check the complete reconstructed context.

## Try it

Python 3.11 or newer; Linux and macOS are the initial supported platforms. Install the versioned wheel:

```sh
python -m pip install https://github.com/pratik-mahalle/compaction-check/releases/download/v0.2.0a1/compaction_check-0.2.0a1-py3-none-any.whl
compaction-check --version
```

For the sample agent and benchmark fixtures:

```sh
git clone --branch v0.2.0a1 https://github.com/pratik-mahalle/compaction-check.git
cd compaction-check
python -m pip install -e .
```

Set your own `TYPESAFE_API_KEY` in the environment, then run:

```sh
python examples/resume.py
python benchmarks/continuation.py --output reports/first-pilot
```

Both commands make real Jev API requests. The runtime has no third-party Python dependencies. GitHub release assets are the distribution channel for this alpha; this release does not require a PyPI installation.

## Included

- Versioned constraint registry with source provenance, scope, supersession, and revocation.
- Pinning with original wording and roles, followed by Jev verification.
- Audit and experimental repair modes, explicit stop conditions, and request/time budgets.
- Structured trace capture, CLI reports, and a local agent that reads disposable CSV files.

## Validation

The offline suite has 77 tests. The continuation experiment used three repetitions at 1, 2, 3, and 5 compaction cycles, changing the required dataset each time.

| Condition | Compliant completions / scheduled steps | Stopped or blocked |
| --- | ---: | ---: |
| Full context | 33 / 33 | 0 |
| Unprotected compaction | 0 / 33 | 0 |
| Pinning + Jev verification | 33 / 33 | 0 |
| Jev-guided repair | 19 / 33 | 14 |

The unprotected agent completed its tasks using the wrong dataset. Six low-confidence repair decisions stopped the affected steps and blocked eight later ones. The behavioral checks inspect actual tool reads and output files independently of Jev's retention verdict.

These are deliberately injected losses in one synthetic task family. Jev is both actor and retention judge. Real-world reliability and confidence calibration remain unproven.

## Pilot scope

Use explicit `mode="pin"` for the sample integration. Audit remains the default. Repair is experimental. The complete serialized context must fit 24,000 UTF-8 bytes; larger contexts are rejected without truncation. APIs and trace formats may change during the alpha.

Jev receives the registered requirement and complete supplied context. Use suitable test data and your own API key. Stored reports contain source wording and evidence. The tool checks retention; host applications remain responsible for tool permissions and downstream behavior.

Share a minimal, sanitized reproduction through [alpha feedback](https://github.com/pratik-mahalle/compaction-check/issues/new?template=alpha-feedback.yml), especially natural compaction losses, false alarms, or constraints that survived but were ignored by the agent.
